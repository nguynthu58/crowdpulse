# crowdpulse

A live audience interaction tool for streamers, creators and event hosts.

- **Overlay:** a browser-source overlay (OBS-ready) that shows live polls and results on stream.
- **Phone voting page:** viewers scan a QR code or open a link to vote from their phone, no app or login needed.
- **Stack:** React + TypeScript frontend (`web/`), Go backend with WebSockets (`server/`).
- **Milestone:** v0.1 by 29 Nov 2026 — create a poll, vote from a phone, see the overlay update live.
